      Como jogar

      • Clique numa casa e digite. O cursor anda sozinho.
      • Clique de novo na mesma casa para trocar entre horizontal e vertical.
      • Use as setas para andar e Backspace para apagar.
      • Aperte Conferir (ou Enter): o LED fica verde se a palavra está certa e vermelho se está errada. Palavras incompletas não acendem.
